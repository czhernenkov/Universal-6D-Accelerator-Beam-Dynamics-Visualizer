Lie mode composes ordered nonlinear element maps T = T_N ∘ … ∘ T_2 ∘ T_1 and applies the composed transport once per pass. Exact drift slices are collapsed; other non-drift slices retain the configured integration resolution. Symmetric drift/kick splittings use Yoshida composition for thick quadrupoles and multipoles; nonlinear multipole and RF kicks are retained. Poincaré plots sample one fixed section per pass. Linear mode concatenates 6D matrices; element mode displays intra-pass samples. This is a composition of implemented element maps, not a single truncated global BCH/Dragt–Finn generator. The local Jacobian symplecticity residual is a numerical diagnostic, not a proof of global validity. Radiation/recoil are excluded from the canonical Hamiltonian tracker; imported 3-D field-map tracking is a separate Boris mode.

Physics model, assumptions & validation references

What is modeled: paraxial 6D element-map tracking, drift and magnetic-element maps, split Hamiltonian quadrupole/sextupole/octupole integration, thin RF energy kicks, linear optics and beam-moment diagnostics. The separate 3D field-map path uses a Boris pusher and is not the same canonical lattice integrator.

What is not implied: no generic measured fringe fields, complete 3D Maxwell-consistent field model, self-consistent PIC space charge, full radiation-reaction model, or external MAD-X/PTC/Bmad/elegant agreement is guaranteed. Imported lattices must be checked for species, units, signs, reference momentum, element conventions and unsupported commands.

Reference trail: Forest — Symplectic integration · Yoshida — higher-order symplectic composition · Bmad manual · USPAS accelerator physics notes · Conte & MacKay, An Introduction to the Physics of Particle Accelerators, especially the coordinate-convention and symplectic-map discussions.

Interpretation rule: a local PASS means only that the tested numerical criteria met their thresholds. It does not certify the model against a real accelerator or an independent tracking code.

Nonlinear studies

Hamiltonian studies automatically disable radiation and stochastic recoil.
Tracking method: multi-turn revolution-by-revolution tracking through the active lattice; each displayed revolution is internally resolved into canonical paraxial element-map composition with fourth-order split maps for quadrupoles and thick sextupoles/octupoles, thin multipole kicks, and nonlinear RF kicks. The map is intended for Hamiltonian studies; imported sector bends can include thin hard-edge E1/E2 wedge focusing. This is not an Enge fringe-field model; radiation and stochastic recoil are excluded. Imported 3-D field maps can be tracked in a separate relativistic Boris-pusher mode. This is not the canonical symplectic lattice tracker and must be benchmarked for the supplied map, units, boundaries and step size.
References: USPAS Accelerator Physics (Litvinenko, Pozdeyev, Satogata) · MacKay, Thoughts on Healy’s Symplectification Algorithm (BNL C-A/AP/215) · Forest, Symplectic integration (1987) · Yoshida, fourth-order symplectic composition (1990) · Bmad manual · Conte & MacKay, An Introduction to the Physics of Particle Accelerators, 2nd ed. (Chs. 3–6, 7–10; Apps. A and E).
Coordinate convention note: this lattice tracker uses (x, x′, y, y′, z, δ) with z as the code's documented longitudinal path/time-like coordinate and δ=Δp/p₀. Conte & MacKay explicitly warn that longitudinal-coordinate signs, canonical momenta, emittance and multipole numbering differ between references (Appendix A); convert conventions before comparing external maps. The sector-bend 6×6 map follows the ideal hard-edge sector model; edge/fringe details are model-dependent.

Field-Map Engine

This engine is deliberately separate from the canonical symplectic lattice tracker. It runs a relativistic Boris pusher in an imported Cartesian E/B map on a Web Worker, with optional direct pairwise bunch space charge and classical Liénard energy-loss correction. The latter two are model-level extensions, not a substitute for validated PIC, full Landau–Lifshitz integration, or quantum synchrotron-radiation emission.
